# Changelog

## 1.0.0

First stable release.

### Highlights

- Live MCSR Random Seed Glitchless pace board from PaceMan.gg
- Minecraft version, streaming, and favorite-runner filters
- Expandable run details with completed splits and estimated elapsed times
- Persistent favorite-runner management
- High-quality, favorite-start, and configurable per-split notifications
- Streaming-only notification gate and conservative fresh-install defaults
- Twitch and PaceMan profile actions from rows and notifications
- Cross-display notification deduplication
- Theme-aware Omarchy controls, colors, typography, and panel behavior
- Configurable refresh interval with stale-data and retry handling
- Mouse and keyboard navigation
- Publication-ready screenshots, documentation, validation, and test harness

### Defaults

- Refresh interval: 15 seconds
- Game version: Minecraft 1.16.1
- Notifications: streaming high-quality runs only
- Favorite and split notifications: disabled until explicitly enabled

### Validation

- Omarchy plugin manifest validation
- 34 QML model tests
- Full Quickshell panel harness
